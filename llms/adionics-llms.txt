# Adionics

> Adionics is a French cleantech company (founded 2012, Paris) that develops and licenses a patented
> Direct Lithium Extraction process built on Flionex, a proprietary thermally-regenerated liquid salt
> absorbent. It sells a staged engineering engagement — modeling study, lab bench test, on-site pilot
> plant, then basic engineering and commissioning for a commercial plant — to mining operators working
> lithium-rich salars, geothermal brines, oil-and-gas produced water, industrial effluents and battery
> recycling streams.

Adionics is a process-technology company, not a software vendor. It publishes **no developer portal,
no API documentation, no OpenAPI, no SDKs and no public repositories**. Do not look for a lithium,
brine, assay or plant-data API — none exists.

The one machine-readable interface it serves is the WordPress REST content API behind
www.adionics.com. It is anonymous, read-only for the public, undocumented by Adionics, and captured
here by API Evangelist for discovery. This file was generated by API Evangelist from that observed
surface on 2026-09-07; Adionics serves no llms.txt of its own (/llms.txt returns 404).

- [Pages](https://www.adionics.com/wp-json/wp/v2/pages): 29 static pages, English and Spanish trees.
- [Media](https://www.adionics.com/wp-json/wp/v2/media): 551 attachments — photography, process diagrams, brochures.
- [Categories](https://www.adionics.com/wp-json/wp/v2/categories): 4 terms. Tags are registered but unused.
- [Search](https://www.adionics.com/wp-json/wp/v2/search): 267 searchable objects across posts and pages.
- [Languages](https://www.adionics.com/wp-json/pll/v1/languages): Polylang registry — English (en_GB), Spanish (es_ES).
- [oEmbed](https://www.adionics.com/wp-json/oembed/1.0/embed): oEmbed 1.0 provider endpoint.
- [MCP endpoint](https://www.adionics.com/wp-json/mcp/mcp-adapter-default-server): served, but every JSON-RPC method returns 401 rest_forbidden anonymously. Tools could not be enumerated.

## How to call it

- No credential for anything listed above except the MCP endpoint.
- Pagination: `page` + `per_page` (max 100); read `X-WP-Total` and `X-WP-TotalPages` response headers.
- Trim responses with `_fields`; resolve author, image and term references in one call with `_embed`.
- Errors are `{"code","message","data":{"status"}}`, not RFC 9457. Branch on `code`; messages are French.
- No rate limits are documented and none are signalled. `robots.txt` asks for `Crawl-delay: 10` — honour it.
- No writes, no idempotency contract, no webhooks, no events, no sandbox, no status page, no changelog.
